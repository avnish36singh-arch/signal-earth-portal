Privacy Policy

1. Static Hosting on GitHub Pages

Signal Earth is a static website hosted using GitHub Pages (a service provided by GitHub, Inc. / Microsoft Corporation). When you visit this site, GitHub may collect visitor IP addresses, browser types, and technical request data for security, diagnostic, and rate-limiting purposes under its own privacy policy. For details on how GitHub handles server access logs, consult the GitHub General Privacy Statement.

2. No Cookies, No Tracking, No Analytics

This website does not set cookies, does not use local storage for tracking, does not run advertising scripts, and does not employ web analytics tools (such as Google Analytics or third-party tracking scripts). Interactive charts execute entirely in client-side memory in your browser.

3. No Accounts, No Data Collection Forms

This site does not offer user accounts, logins, newsletter subscriptions, or web forms. You cannot register or submit personal profile data on this website.

4. Direct Email Communications

If you choose to contact the maintainer by email, your email address, name, and the content of your message will be received directly in the maintainer's mailbox. That information is used solely to respond to your inquiry and is retained only as long as needed to handle the correspondence. Your email address is never sold, rented, or shared with third parties.

Deletion Requests: If you have previously communicated by email and wish for past email records to be deleted from the mailbox, send a deletion request to TODO[ME]: contact email address.

5. Outbound Links to Third-Party Services

This site includes outbound links to external platforms, including GitHub, LinkedIn, Instagram, NASA POWER, and CPCB. When you click an external link, the privacy practices of that destination platform govern your browsing on their service.

6. Children's Privacy

This website publishes academic and technical air quality data analyses intended for general educational audiences. It does not target, market to, or knowingly collect data from children under the age of 18.

7. India's Digital Personal Data Protection Act, 2023

Because this site does not collect personal data through web forms, accounts, or cookies, data processing activities are limited to voluntary email correspondence and server-level hosting logs maintained by GitHub Pages. In accordance with the principles of India's Digital Personal Data Protection Act, 2023 (DPDP Act), any personal data received voluntarily via email is processed solely for the specified purpose of communication, with rights of correction and erasure respected upon request.
