Data Protection & Privacy

Privacy Policy

Last updated: October 2026. This policy explains our minimal, privacy-respecting architecture.

1. Static Hosting and Server Logging

Signal Earth is compiled as a static website hosted on Netlify's global edge network. When you visit this website, Netlify's edge servers automatically log standard HTTP request metadata:

  • Your IP address
  • Date and timestamp of the request
  • Requested URL path and query parameters
  • HTTP response status code
  • Browser user-agent string and referring URL

These server access logs are retained transiently by Netlify for DDoS mitigation, performance monitoring, and security diagnosis. The maintainer does not use these server logs for personal profiling or ad retargeting.

2. Zero Cookies and Zero Analytics Trackers

Signal Earth does not set HTTP cookies. We do not embed Google Analytics, Meta Pixel, Hotjar, fullstory, or any third-party behavioral telemetry. We do not serve third-party advertisements or sell user information.

3. Client-Side Browser Storage

The site uses browser localStorage solely to remember your chosen visual theme preference (se_theme_mode = "dark" or "light"). This preference remains stored on your device and is never transmitted to our servers.

4. User Communications

There are no user accounts, registration portals, or comment forms on this website. If you contact the author directly via email (avnish36singh@gmail.com) or via GitHub Issues, your correspondence is used solely to respond to your technical question or process your methodological feedback.
