01 : Academic Citation

How to Cite Signal Earth

If you use Signal Earth analyses, processed data, or visualizations in academic research, reports, or journalism, please cite the project as follows:

APA Format (7th Edition)

02 : Software & Frameworks

Open Source Software and Frameworks

Signal Earth is built entirely with open-source web standards and geospatial rendering libraries:

Component Version / Source License Role in Signal Earth
Three.js r160 (mrdoob) MIT License WebGL 3D scene graph, camera projection, and atmospheric glow shader.
Globe.gl v2.32.2 (Vasco Asturiano) MIT License Country polygon mesh extrusion, hover tooltips, and click-navigation.
Natural Earth 1:110m Cultural Vectors Public Domain Sovereign country boundary geometries and centroid coordinates.
NASA Blue Marble Visible Earth / MODIS Public Domain / NASA Open Data Planetary surface texture base and night lights radiance maps.
Open Typography Outfit, Inter, JetBrains Mono SIL Open Font License 1.1 High-legibility editorial headings, body text, and tabular telemetry.
